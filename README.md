# MultBilim — studiya sayti (prototip)

O'zbekistondagi **MultBilim** animatsiya studiyasi uchun bosh sahifa prototipi.
Statik sayt — build talab qilmaydi, GitHub Pages'dan to'g'ridan-to'g'ri beriladi.

## Loyihalar

Alpomish · Ikki Dunyo · Zij · Megavoylar · Sehrli Qalpoqcha · Meva-Cheva

## Tuzilishi

```
index.html      butun sahifa (146 KB)
img/            49 ta rasm — loyiha hujjatlaridan
fonts/          Archivo + JetBrains Mono (latin subset)
favicon.svg
```

## Imkoniyatlar

- Uch til: uz / ru / en (tanlov brauzerda saqlanadi)
- Yorug' va qorong'i rejim
- Har loyihaning o'z rang uslubidagi ichki sahifasi
- Rasm ko'rgich (klaviatura strelkalari bilan)
- Mobil menyu
- `prefers-reduced-motion` hurmat qilinadi

bilan almashtirilishi kerak. YouTube ko'rish sonlari kanallarning ochiq RSS
ma'lumotidan olingan.
